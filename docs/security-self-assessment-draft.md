| 暂停恢复 | 运行、节点、待办和会话记忆写入数据库 | 跨请求消歧、确认与认证测试 |
| 人工接管 | 未知意图、疑似注入或用户请求可暂停并转人工 | 自动与手动接管测试 |

| 体验数据隔离 | 每个会话使用独立用户、账户、流水、卡片、订阅和 Agent 数据 | 双用户余额隔离与用户级重置测试 |
| 公开访问保护 | 会话容量上限、数据库分钟窗口限流和管理员令牌统计 | 限流与管理员权限测试 |

## 已知风险与上线前措施

| 风险 | 当前状态 | 正式环境措施 |
| --- | --- | --- |
| 演示身份由 `X-Demo-User-ID` 上下文提供 | 仅适用于单用户沙箱 | 接入银行 OAuth/OIDC、会话绑定与设备证明 |
| OTP 为配置中的固定演示码 | 仅用于比赛演示 | 接入短信/人脸/U 盾服务，使用一次性随机挑战 |
| 默认 HMAC 密钥存在开发回退值 | 本地可运行 | 由 KMS/HSM 注入高强度密钥并定期轮换 |
| SQLite 不支持等价行级锁 | 仅用于测试 | 正式运行统一使用 PostgreSQL |
| 审计链未外部锚定 | 可检测常规篡改 | 周期性把链头写入独立 WORM 存储或签名服务 |
| 当前熔断状态保存在数据库 | 单服务可用 | Redis 原子计数、设备/IP/账户多维限流 |
| 提示注入检测基于规则信号 | 可覆盖演示攻击 | 增加输入分区、工具参数 schema、对抗样本评测和策略更新 |
| 可选外部模型会接收最少化用户文本 | 默认离线适配器不外发 | 上线前完成数据分级、用户授权、区域和供应商合规评估 |
| 理财收益区间来自演示产品库 | 仅用于功能展示，不构成投资建议 | 正式接入产品主数据、适当性双录、行情时效和风险揭示 |
| 未连接真实银行核心 | 符合沙箱范围 | 上线前完成双录、清算对账、补偿及灾备演练 |
| Demo 重置会删除全部沙箱记录 | 仅在 development 环境开放 | 生产配置强制禁用该路由并实施数据库权限隔离 |
| 鲜花、蛋糕与配送为可信商户模拟目录 | 仅展示编排与授权链路，不产生真实订单 | 正式接入签约商户 API、库存锁定、价格确认和退款补偿 |
| 邀请码属于共享秘密 | 适合小范围比赛体验，不能替代客户身份认证 | 定期轮换、限制传播范围；正式系统接入 OAuth/OIDC 和设备证明 |

## 结论

当前实现适合作为竞赛沙箱 Demo，已经证明语言模型不能直接授权或执行资金操作。它不是生产银行系统；身份认证、真实 MFA、密钥托管、分布式限流、外部审计锚定和银行核心适配必须在正式环境补齐。
