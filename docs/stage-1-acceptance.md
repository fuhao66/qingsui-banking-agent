# 第一阶段验收

## 验收目标

- [x] 工作区具备清晰的前后端单仓结构。
- [x] 提供可识别的银行 Agent 第一屏，而不是通用脚手架页面。
- [x] API 提供存活检查、依赖就绪检查和系统状态接口。
- [x] PostgreSQL 与 Redis 已进入本地容器编排。
- [x] 前后端均提供容器镜像定义。
- [x] 环境变量提供可提交的示例文件，敏感文件已忽略。
- [x] 数据库迁移和自动测试目录已经建立。
- [x] 架构文档明确模型、权限引擎和执行器的边界。

## 第二阶段入口条件

1. 前端生产构建通过。
2. API 基础测试通过。
3. Docker 可用时，四个服务能够健康启动。
4. 不在第一阶段静态页面上继续堆叠业务逻辑，下一阶段统一改为 API 驱动。
